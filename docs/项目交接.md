## 3. 估值与情景计算

历史使用2027E利润70%+2028E利润30%作为加权远期利润锚（旧基准；继续研究时应检验是否仍合理）。

- 加权利润 = 0.7×2027E归母净利润 + 0.3×2028E归母净利润。
- Forward PE = 当前**完整权益市值** / 加权利润；亏损、利润接近零时应标记NM，不可虚构PE。
- Bear/Base/Bull目标市值 = 对应情景合理利润 × 对应合理PE（或经说明的分部估值）。
- 情景收益率 = 目标市值/当前可比市值 − 1；注意增发、股本变动、分红、A+H总市值与A股价格口径一致性。
- 必须区分利润增长贡献与估值扩张贡献，禁止用高目标PE掩盖利润缺口。
- Base>40%强制：目标新增市值=Base目标市值−当前市值；新增利润等价=目标新增市值/合理PE。该等价量是估值检验辅助量，**不等同于实际所需增量利润**；还需直接核对目标净利润−基准净利润，并拆解订单、收入、毛利、费用和税率。
- 若上涨只是股价反弹而利润不变，Forward PE随股价上升、情景收益率下降；若股价下跌但盈利预测同步下修，不能机械加分。
- 旧目标价固定时新Base收益率=(1+旧Base收益率)×旧价格/新价格−1；仅可作敏感性分析，不能替代重估。
